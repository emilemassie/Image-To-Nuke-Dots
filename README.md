# ImageToNukeDots 🔴🟢🔵

Convert any image into a matrix of colored **Dot nodes** directly inside your **Foundry Nuke** node graph to create custom, node-based halftone image art.

## ✨ Features

* **Instant Node Art:** Automatically sample image pixel data and convert it into a grid of colored Dot nodes inside Nuke.
* **Custom Resolution & Scale:** Adjust dot spacing and sampling resolution to balance node count with visual detail.
* **Standalone Executable:** Quick, lightweight standalone desktop app—no complex script setups required inside Nuke.
* **Clean Organization:** Generates organized node layouts ready to copy, paste, or drop directly into your DAG.

---

## 🚀 Quick Start

1. **Download:** Grab the latest release for your OS from the **Releases** tab.
2. **Load Image:** Open `imageToNukeDots`, select your source image file (`.png`, `.jpg`, etc.).
3. **Adjust Settings:** Fine-tune dot resolution and node spacing.
4. **Export to Nuke:** Paste the copied node tree straight into your Nuke Node Graph (`Ctrl+V` / `Cmd+V`) or press the Copy To Clipboard Button.
